Welcome to SRMusic

🔒 Sign-in required

You'll need to sign in with your YouTube Music cookie before you can search, browse, or play anything — the web app has no anonymous mode.

How do I get this?
  1. While signed in to music.youtube.com, open DevTools (F12 or Cmd+Opt+I) → the Network tab.
  2. In a new tab, open music.youtube.com/youtubei/v1/account/account_menu?prettyPrint=false — this is the exact request SRMusic itself uses to check a cookie actually works, so it's always there and easy to find (filter the list by "account_menu" if needed).
  3. Click that request, then open Headers → Request Headers (not Response Headers), and find the line starting "Cookie:".
  4. Copy everything after "Cookie: " and paste it below.
⚠️
🔒 This is a live login credential — treat it like a password. It's sent straight to your own SRMusic server and stored behind an opaque session cookie there; it's never shown again or logged.
